# E3 — Object Detection: YOLOv8n (GroupShuffleSplit, Zero Data Leakage)

Real-time object detection using **YOLOv8n** for parking-lot occupancy detection on the **PKLot** dataset with **GroupShuffleSplit stratification by capture date** to eliminate data leakage.

## Key Difference from E2 (baseline YOLO)

The baseline YOLO experiment (E2, see `yolo/`) uses standard train/val/test splits from Roboflow. However, PKLot photographs the **same parking lot every 5 minutes**, so images from the same day are highly correlated.

**Problem:** Without date-aware splitting, images from the same day can appear in both training and test sets → model "memorizes" patterns → artificially high test accuracy.

**Solution:** This experiment (E3) uses **GroupShuffleSplit stratified by capture date** to guarantee:
- ✅ **0% date overlap** between splits
- ✅ All images from the same day stay together in one split
- ✅ Fair, realistic evaluation

## Dataset

Original PKLot dataset: **12,416 images** from **100 unique days** (2012-09-11 to 2013-04-16).

Reorganized with GroupShuffleSplit by date:

```
TRAIN:  8,706 images / 69 unique days (70%)
VAL:    2,087 images / 16 unique days (15%)
TEST:   1,623 images / 15 unique days (15%)

✅ Zero date overlap across all splits
```

### Classes

Three classes (from original COCO annotations):
- `0: spaces` — generic parking space
- `1: space-empty` — empty parking space
- `2: space-occupied` — occupied parking space

  - Validates: 100% image-label matching, 0% overlap

## Code Conventions

- **Dataset stratification**: `GroupShuffleSplit(groups=dates)` ensures all images from the same day are in the same split
- **Format conversion**: COCO `[x, y, w, h]` (pixels) → YOLO `<class> <x_center> <y_center> <w> <h>` (normalized 0-1)
- **Validation**: Automatic assertions for zero date overlap and 100% image-label matching
- **Results format**: Metrics saved as CSV for reproducibility
